Project Demonstrations

AI Robotic Controller Demonstration

This project demonstrates an AI-based robotic control system capable of autonomous decision-making and navigation. The controller was designed to process environmental inputs in real-time and generate adaptive movement strategies for the robotic platform.

Technologies used include machine learning algorithms, robotics control systems, and real-time sensor integration for intelligent agent behaviour.

DepthAI + MediaPipe Perception Pipeline

This demonstration showcases a real-time computer vision perception pipeline developed using DepthAI and Google's MediaPipe framework. The system performs human and object perception tasks with low latency.

The pipeline integrates embedded AI acceleration, camera depth estimation, and pose/feature tracking to support robotics and intelligent interactive systems.

Magnetic Confinement Simulation

This simulation visualises magnetic confinement dynamics and particle interactions under electromagnetic fields. The project explores computational modelling techniques used in physics simulations and plasma-related systems.

The simulation was developed to investigate stability behaviours and dynamic particle motion using numerical modelling approaches and scientific computation tools.
