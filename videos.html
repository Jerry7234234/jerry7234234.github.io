Project Demonstrations

An extensive study in modern robotics and sustainable development

This project demonstrates an AI-based robotic control system capable of autonomous decision-making and navigation. The controller was designed to process environmental inputs in real-time and generate adaptive movement strategies for the robotic platform.

Technologies used include machine learning algorithms, robotics control systems, and real-time sensor integration for intelligent agent behaviour.

An extensive research in Lidar properties for robotic applications

This demonstration showcases a real-time computer vision perception pipeline developed using DepthAI and Google's MediaPipe framework. The system performs human and object perception tasks with low latency.

The pipeline integrates embedded AI acceleration, camera depth estimation, and pose/feature tracking to support robotics and intelligent interactive systems.

Leorover mobile robot project

The objective of this project is to design and develop a fully autonomous robot capable of navigating a rectangular search area with randomly placed obstacles to collect 3 coloured cylinders and return them to matching-coloured bins at the rover’s starting point within a 20-minute mission time.

Our mobile robot offers a compact design and is suitable for open space exploration and salvation tasks involving multiple small objects. It is especially useful in environment that could be hazardous to human workers. The robot uses economic materials and a modular design which allows for any consumers, researchers or hobbiests to work on. In summary, our robot is suitable for both industrial applications as well as laboratory researching.
